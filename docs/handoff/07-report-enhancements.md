# 07 · 微信支付宝报告增强

版本：v1.1｜2026-09-30。本文补充一期报告需求，以下四项已在本地报告原型实现；公司平台、数据库、权限和服务端查询仍按 01–06 实施。银行流水不纳入本次开发，客户 H5 仍仅用于上传。

## 1. 信用履约独立展示

报告分为“借款及还款往来”和“信用履约”两个模块，各有渠道明细和 7/15/30/90/180 天、全部周期表。

- 花呗、白条、抖音月付、分付及明确的信用卡还款文字归入信用履约；借呗、网商贷、微粒贷、京东金条等明确借贷产品保留在借还款模块。
- 主要场景优先级：租赁 → 明确借贷产品 → 信用产品 → 其他借还款文字/机构 → 回收。每条记录只有一个主要场景；画像仍可重叠。
- 依据交易对方、商品、类型、备注识别。仅付款方式出现信用卡/花呗，不等于信用履约事件。
- 退款优先识别，营销红包单列。还款文字只有原方向为支出才计入“还款文字线索”金额；中性或收入方向保留原标记，不改记支出。
- 周期以报告账单截止日为锚点，仅响应平台筛选；自定义日期控制渠道明细，两者在页面就近标明。窗口可重叠，不能相加。

此模块只描述已出现的交易，不输出剩余欠款、额度、逾期或履约评分。

## 2. 薪资收入线索

仅在原方向为收入的记录中扫描交易对方、商品、类型、备注和状态，命中“工资、薪资、薪酬”。排除退款标志及含“退款、退还、退回、冲正、撤销、取消、失败、工资卡、非工资、非薪资、借款、贷款”的文字。

展示识别收入、命中笔数、命中月份/所选区间月份、最近日期、月度分布及来源。来源按平台与交易对方原文精确分组。日期及平台变化后重新计算；只选部分月份时，金额只含所选日期内流水。区间中的无命中月保留为“未识别”，不插值、不估算。

每笔命中保留关键词依据和原记录 ID。月度/来源均可下钻，集合与汇总完全一致。无命中时显示“当前范围未识别到明确薪资收入文字”，不确认雇主、任职、固定发薪日或工资稳定性。

## 3. 重点交易摘要

| 组别 | 纳入条件 | 展示 |
| --- | --- | --- |
| 大额收支 | 原方向收入/支出，单笔金额 ≥ 1,000,000 分（10,000 元） | 笔数、收入、支出、原流水 |
| 夜间收支 | 原方向收入/支出，北京时间 22:00:00–次日 05:59:59 | 笔数、收入、支出、原流水 |

两组可以重叠，不合并成异常总数，不把发生时段或金额大小自动视为风险。收入沿用原口径，包含退款；中性记录不进入摘要。统一响应日期及平台筛选。当前阈值写入规则版本，不提供审核人员临时修改阈值的配置入口。

## 4. 主要资金流向

图的左侧为收入来源，右侧为支出去向；中心分别展示所选范围收入、支出总额。同名对方在不同平台分别成组，名称缺失时展示“未标注交易对方”。

每侧按金额排序展示前 5 个交易对方，其余合并为“其他交易对方”；所有节点金额之和必须等于该侧总额。只展示非零收入/支出，退款收入保留，中性记录不进入图。零元流水仍保留在账单明细，但不形成金额流向节点。

每个节点保留准确的流水 ID 集合和方向，支持鼠标、键盘下钻；“其他”也可查看。图表示收支分布，不表示两侧对应记录属于同一资金链，不跨平台自动抵扣转账。

## 5. 数据、接口与版本

`insights` 新增 `credit_periods` 和 `review`。`review` 中 salary 保存证据、月度及来源，large 保存阈值，night 保存时间组，flows 保存平台/对方分组。所有金额为整数分，所有集合保留原记录 ID。

当前原型版本：场景规则 `2026-09-30-scenes-v2`；review 规则 `2026-09-30-review-v1`。原始账单总额与记录不因这些标签改变。公司生产实现需要把衍生数据与报告版本和规则版本绑定；历史报告不随规则升级静默变化。

05 中新增的 credit-periods、salary、transaction-highlights、fund-flows 是生产接口需求，当前独立 HTML 仍在本地计算与筛选，尚未提供这些后端接口。生产下钻应由后端返回授权范围内的稳定标识，并检查业务单/报告权限，不能信任客户端传入记录 ID。

## 6. 交接与验证

复用 `review_analysis.py` 的规则、`review-metrics.js` 的筛选聚合契约及 `review-ui.js` 的展示。既有 `scene_analysis.py`、`scene-ui.js` 和规则文件负责信用拆分。`render_report.py` 统一内嵌脚本，`refresh_reports.py` 同步刷新四份已有报告。

验收详见 06 的 T31–T34。合成测试覆盖退款优先级、原交易方向、信用付款方式、薪资排除项、缺月、10,000 元边界、22:00/06:00 边界、同名跨平台、前 5 + 其他以及筛选空结果。真实样本检查仅保存在本地受控输出，不将真实交易写入 Git。
