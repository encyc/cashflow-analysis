# 06 · 开发拆分、验收与待确认事项

本需求包用于估时与评审，不承诺开发排期。公司评审确认人员、技术栈、接口和业务量后，由各工作包负责人给出人天、依赖及上线窗口。

## 1. 工作包与交付物

| 工作包 | 内容 | 依赖 | 完成证据 |
| --- | --- | --- | --- |
| W1 需求及集成基线 | 确认业务 ID、身份、SSO、权限、账期、格式、保留和容量 | 公司系统负责人参与 | 已确认接口/数据字典/权限矩阵、决策记录 |
| W2 解析服务封装 | 统一函数入口、模板识别、ZIP 解压、凭据、资源限制、身份校验 | W1 格式与身份规则 | 干净环境可运行、样本回归、错误码与版本产物 |
| W3 数据与异步任务 | 表/索引/迁移、私有存储、幂等、状态机、发布事务、任务恢复 | W1、W2 契约 | 真实入库、重试无重复、补件不覆盖旧报告 |
| W4 客户采集 H5 | 业务绑定、验证/授权、双平台上传、补密码、替换、状态 | W1、W3 接口 | Android/iOS 真机闭环记录 |
| W5 审核平台 | 列表/材料/报告/版本/异常、既有图表、筛选下钻、权限 | W3 报告契约 | 按业务单打开报告、金额/明细一致 |
| W6 业务系统联调 | 入口、回调/查询、状态同步、审计采用版本 | W3、W5 | 成功/补件/失败/乱序事件均通过 |
| W7 部署及上线 | 构建、迁移、配置、监控、限额、回滚、备份恢复、灰度 | 全部工作包 | 测试环境复现、验收签字、生产灰度记录 |

W2–W5 可由公司根据接口完成度安排并行；需求契约先固定。验收不只看页面截图，要检查数据库记录和故障场景。

| T27 | 商户/备注含脚本片段 | 页面按文本显示，不执行；API 和页面无个人信息外传 | W5 |

| T30 | 采集成功但生成失败且已有 V1 | 展示“V1 可用、最新尝试失败”；不把上传成功当报告成功 | W3/W5 |
| T31 | 信用履约与借贷拆分 | 花呗/白条等独立；借呗/网商贷仍属借贷；付款方式不触发；退款及营销不计还款，非支出方向不变 | W4/W5 |
| T32 | 薪资收入线索 | 仅明确收入文字，排除退款/失败/借贷；月度和来源下钻一致，缺月及无命中不推断没有工资 | W4/W5 |

## 3. 性能与兼容验收建议值

尚无公司业务量及生产资源。以下用于启动压测，需在评审中确认或调整，不是本次已经测得的数据。

| 项目 | 初始目标 | 测试前提 |
| --- | --- | --- |
| PC 列表/明细 API | P95 ≤1 秒，错误率 <1%（人为非法请求单列） | 单报告 10,000 笔、20 名审核并发；明确缓存和机器配置 |
| PC 报告首屏 | P95 ≤3 秒 | 公司目标网络、已生成报告，按实际客户端记录 |
| 文件解析 | 单份 100 页、5,000 笔以内 P95 ≤120 秒 | 不含上传/等待时间，文本型 PDF；Worker 并发与硬件记录 |
| 队列等待 | 正常规划负载下 P95 ≤60 秒 | 公司先给出每分钟峰值任务数；不可用无限低负载宣称达标 |
| 文件受理 | 文件流完整收到后 ≤3 秒给出受理结果 | 存储健康；不含客户上行时间 |
| 兼容 | 公司指定当前受支持桌面浏览器、iOS/Android 微信浏览器 | 记录具体版本与至少各一台真机 |

若目标不满足，定位是模板性能、硬件、并发、数据库索引还是网络；调整后复测，不能用减少明细或跳过核验换取成功率。

## 5. 给需求方的提醒

**最容易少报工作量的是自动化闭环。** 上传页面、报告页面之外，还要算上解压、身份核对、失败补件、异步任务、数据库迁移、业务联调、权限和运维。

**明确数据口径再估时。** 同人合并不等于跨平台转账抵扣；场景识别不等于真实负债；原始收入不等于工资。若业务需要这些新结论，需要另立数据来源和验证要求。

**当前词库和模板只覆盖已有样本。** 接入真实客户后会出现版式变化、扫描件、错误密码和姓名不符，需要有人处理，不能只计算服务器费用。

**数据治理要成为验收项。** 不再通过邮件发送流水与密码；原件、报告、客户身份和删除/保留各有负责人。具体监管与授权义务由公司结合业务确认，本包不代替公司法律审核。

**资料质量信息留在后台。** 审核报告继续面向审核人员；解析检查、失败页码、模板版本属于运营/技术诊断，不能因前台删掉模块就停止校验。

## 6. 上线交付清单

- 可维护源码、可重复构建的依赖锁与镜像、规则版本包、测试样本管理说明。
- 实际 DDL/迁移/索引、数据字典、OpenAPI 或公司接口文档、错误码与回调联调记录。
- PC 平台与客户 H5、角色权限配置、公司业务入口、授权文案和品牌信息。
- 配置模板（无密钥）、部署/回滚手册、监控告警、任务重试与故障处理手册。
- 真实样本回归、真机兼容、越权/上传安全、性能、恢复、删除验证报告。
- 业务/技术/测试/运维的验收记录，未关闭问题及明确责任人。

全部 P0 用例通过，开工/上线阻塞事项关闭，生产配置无占位文案，才可灰度上线。页面完成或本地单元测试通过不能单独作为交付完成依据。
